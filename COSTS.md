# Расход по тестам

Токены — общее число токенов субагента, которое сообщает система (вход + выход + кэш, суммарно по всем его запросам;
разбивки нет). Стоимость — **оценка, API-эквивалент** по смешанной ставке из `site.config.json`
(`blended_usd_per_mtok`), а не реальное списание. После сверки с реальным расходом ставку можно подправить —
`tools/build.py` пересчитает сайт.
