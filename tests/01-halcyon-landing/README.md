# 01 · Halcyon Landing

Лендинг вымышленного производителя аналоговых синтезаторов в стиле «швейцарский брутализм × японский hi-fi каталог 70-х»: canvas-осциллограф в hero (реагирует на мышь, фосфорный шлейф), сетка из 6 инструментов со staggered-reveal, горизонтальная лента patch notes на sticky-скролле, таблица характеристик как в печатном мануале, контурный wordmark в футере; кнопки «Listen» играют ноту через WebAudio.
Открыть: `v2/index.html` (финал) или `v1/index.html` (one-shot) через локальный сервер или двойным кликом. Без библиотек, только Google Fonts.
v1 работал, но заголовок HALCYON переносился («HALCYO/N»), wordmark в футере обрезался, подпись в hero уходила за край. В v2 — fit-text по ширине, перерисованный reveal карточек, лёгкий grain без blend-оверлея, мобильная вёрстка.
FPS в песочнице нестабилен из-за параллельной нагрузки (отдельный замер hero ≈ 55–60 fps).
