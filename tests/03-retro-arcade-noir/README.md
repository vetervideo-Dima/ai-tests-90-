# 03 · Retro Arcade Noir

**v1** — one-shot лендинг магазина ретро-игр «Midnight Cartridge» в стиле arcade-noir: canvas-город под дождём с неоновой вывеской и молниями, карточки картриджей с пиксельными спрайтами, автоигра Pong в аркадном автомате, «Case Files», рассылка, корзина. Работает без ошибок; недочёты: заголовок героя наезжает на подпись под навбаром при 1280×720, тяжёлое зерно, штампы перекрывают подписи, на мобиле вывеска лезет на текст.
**v2** — ответ на второе сообщение «Make it light, more pastel coloured & flowery»: «Daydream Cartridge» — пастельный город с цветочными ящиками на окнах, облаками, падающими лепестками (клик по герою — взрыв лепестков), бабочками, лугом с цветами, вывеска ARCADE в лианах, «Petal Pong», карточки на лугу, «Love Letters» с washi-скотчем. Плюс исправления вёрстки v1, мобильная версия (2 колонки карточек, панель героя), пререндер слоёв и спрайтов (≈58 FPS в песочнице против 12 у v1).
Открыть: `v1/index.html` / `v2/index.html` через локальный сервер или двойным кликом. Шрифты — Google Fonts (с fallback).
