Одностраничное портфолио «Elena Voss Photography» (Tailwind из vendor): hero с 3D-рамкой (CSS 3D + JS, наклон за мышью), бесконечная masonry-сетка с fade-in, 3D-лайтбокс в стиле coverflow, параллакс в About, горизонтальный журнал с закреплением, форма контакта. Фото заменены процедурными SVG-сценами (горы, море, дюны, лес, арки, луна, портрет, натюрморт).
Открыть: `v2/index.html` (лучше через `python3 -m http.server` из корня репозитория, иначе не найдётся `../../../vendor`).
v1: всё рендерится без ошибок, но на десктопе сломан журнал: `overflow-x:hidden` на body отключил `position:sticky`, и секция прокручивается пустой. Кроме того, догрузка сетки сдвигает нижние секции.
v2: исправлены sticky (`overflow-x:clip`) и догрузка (без прыжков, учёт переходов по меню), убраны полосы тумана, добавлены отбрасываемая тень у рамки и раскрытие лайтбокса от плитки, исправлена мобильная вёрстка hero и журнала.
Шрифты из Google Fonts (есть fallback). Проверено в headless Chromium (desktop + mobile), ошибок в консоли нет.
