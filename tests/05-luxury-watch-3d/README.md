# 05 · Luxury Watch 3D — Meridian No. 7

Лендинг часов, собранных процедурно в Three.js: корпус-lathe, ушки, рифлёная заводная головка, керамический безель с гравировкой (bump + metalness-маска), купольное сапфировое стекло (transmission + iridescence), солнечный циферблат (anisotropy-map), стрелки по реальному локальному времени, механизм (шестерни, мосты с Côtes de Genève, рубины, баланс, ротор). Скролл: 3/4 → взрыв-схема → макро циферблата → ремешки (4 материала, клик по свотчу или по ремешку) → резерв. Свет студийный, мягкие тени, film grain + виньетка в пост-обработке.
Открыть: `v2/index.html` через локальный сервер из корня репозитория (`python3 -m http.server`), three берётся из `vendor/`.
v1 работает, но в песочнице слишком тяжёлый (скриншот `check.mjs` упирался в таймаут), bloom пересвечивал стекло, герой обрезан. В v2 — адаптивное качество, скрытие невидимого механизма, приглушённый bloom, ремешок прячется при разборке, хлястики, мобильная раскладка.
В песочнице (SwiftShader + параллельная нагрузка) FPS 3–6; на реальной GPU ожидается плавно.
