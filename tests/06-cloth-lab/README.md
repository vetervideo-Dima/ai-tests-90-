# 06 · Cloth Lab

Одностраничный «Interactive Cloth Lab» на чистом WebGL2 без библиотек: Verlet-ткань 64×40 (2560 частиц, ~15k связей) с аэродинамикой по треугольникам, флаг «WINDHALL» с текстурой из canvas, velvet-sheen шейдер, плоские тени, панель со слайдерами Wind / Turbulence / Stiffness / Sheen, захват и разрыв ткани мышью (Shift или режим Tear).
Открыть: `v2/index.html` (или `v1/`) — работает двойным кликом, зависимостей нет.
v1 рендерил всё корректно, но поверх страницы всегда висел оверлей «WebGL 2 is not available» (CSS `display:grid` перебивал атрибут `hidden`), и флагшток наезжал на текст. В v2 это исправлено, ускорен солвер, переделана мобильная раскладка.
В песочнице (SwiftShader, загруженный CPU) 5–12 FPS; на обычном ПК симуляция укладывается примерно в 3–6 мс на кадр.
