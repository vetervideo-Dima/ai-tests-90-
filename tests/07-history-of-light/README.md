# 07 · A Short History of Light
Скролл-лонгрид на чистом canvas без библиотек: 7 глав (огонь, свеча, газовый фонарь, лампа, неон, LED, лазер), у каждой — закреплённая полноэкранная сцена, которая морфится по прогрессу скролла; крупные serif-буквицы, прогресс-бар в виде спектра с линиями Фраунгофера, цветовая температура страницы плавно меняется между главами.
Открыть: `v2/index.html` (итог) или `v1/index.html` (one-shot) через локальный сервер или двойным кликом; шрифты — Google Fonts с fallback.
v1 работал сразу без ошибок; в v2 исправлены пересвеченные газовые фонари, «белый блин» вместо пламени, пустой центр лазерной мандалы, смещённые подписи прогресс-бара, обрезанная буква в заголовке; неон переведён с shadowBlur на дешёвый bloom, лампы — на спрайты, добавлен лимит пикселей canvas и мобильная раскладка.
FPS в песочнице (SwiftShader) низкий и шумный на тяжёлых сценах — реальный замер на GPU не проводился.
