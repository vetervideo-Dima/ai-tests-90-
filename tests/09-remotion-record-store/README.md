Remotion-проект (Root.tsx + композиция `GrooveBasement`, 1080×1920, 30fps, 15 с): виниловая пластинка влетает с motion blur (`@remotion/motion-blur`), три слогана в стиле kinetic typography, сетка из 9 обложек на CSS/SVG, штамп ценника с тряской камеры, логотип в финале. Оба рендера сделаны в песочнице через headless Chromium: `v1/groove-basement.mp4` и `v2/groove-basement.mp4`.
v1 работал сразу. Проблемы: заголовки выходили тонким шрифтом (без Arial Black фолбэк был не жирный), надпись на яблоке пластинки обрезалась, MP4 весил 18 МБ (пережат через ffmpeg -crf 26 до 4.4 МБ, содержимое то же).
v2: жирные шрифты-фолбэки, подпись по полной окружности, тёплый прожектор, свечение, тень и пылинки, наклон пластинки при влёте, более сильный motion blur, параллакс-эхо слоганов, блик на обложках, в финале пластинка крупнее и с тонармом. Grain стал реже обновляться, итог 9.1 МБ.
Локальный запуск: `cd v2 && npm i && npx remotion studio`, рендер: `npx remotion render GrooveBasement out.mp4 --codec=h264 --crf=23`.
