# 11 · Manim Pythagoras
Сцена Manim CE (`PythagoreanTheorem`): треугольник, квадраты на сторонах, морфинг в a²+b²=c², затем доказательство перестановкой четырёх треугольников. v1 (one-shot) отрендерился с первого раза (39.8 с); v2 (37.9 с) — морфинг по площади (разбиение c² высотой, как у Евклида), треугольники скользят строгими переносами, крупнее композиция, вывод через сравнение площадей.
Смотреть: `v1/pythagoras.mp4`, `v2/pythagoras.mp4` (720p30). Локальный рендер (нужны Manim CE, LaTeX, ffmpeg): `manim -pqm v2/pythagoras.py PythagoreanTheorem` (`-pqh` — 1080p).
Проблемы: рендер прошёл в обеих версиях; в v1 «морфинг» — лишь растворение копий, а треугольники деформируются вместо скольжения.
