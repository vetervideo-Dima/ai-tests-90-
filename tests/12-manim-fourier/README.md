# 12 · Manim Fourier
Скрипт `fourier.py` на Manim CE: 3 сцены (сумма трёх синусов, «намотка» на окружность с точкой центра масс, пики спектра на 1/2/3 Гц) с подписями. Рендер в -qm (720p30) прошёл, сцены склеены в `v1/fourier.mp4` и `v2/fourier.mp4` (~109 с, ~10 МБ).
v1 работает как есть; мелкие огрехи: подписи «A = …» налезали на «Hz», в readout смешивались шрифты Text и LaTeX, оформление было простым.
v2: тёмно-синий фон, шрифт Inter, свечение кривых и точек, след центра масс, полоса-индикатор расстояния, заливка под спектром, курсор частоты, подписи в плашках, кеширование центра масс.
Локальный рендер: `manim -qm -a fourier.py`, затем склейка через `ffmpeg -f concat` (команды в шапке файла).
