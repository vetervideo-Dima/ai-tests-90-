# 13 · Tokyo Street Prompts
Знаменитый промпт Sora переписан под Veo, Kling, Seedance и Runway (план, объектив, движение камеры, свет, тайминг, звук, негативы) + раскадровка сиквела из 6 кадров.
v1 (`v1/result.md`) — one-shot; v2 (`v2/result.md`, копия в `result.md`) — исправленная версия: настройки и сводная таблица по моделям, единое описание персонажа, негативы — так, как каждая модель их реально принимает, звук только там, где он генерируется нативно; у раскадровки — длительности, правила монтажной непрерывности, модель для каждого кадра.
Открыть: любой просмотрщик Markdown. Промпты не прогонялись в самих моделях (нет доступа) — проверка только по чек-листу промпта и по известным особенностям моделей; версии моделей быстро меняются.
