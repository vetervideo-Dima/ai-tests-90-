# 15 · Spaghetti Test
Текстовый тест: 5 промптов для text-to-video с нарастающей сложностью (руки, вилка, физика спагетти, жевание, стабильность лица) с оригинальной героиней — оперной певицей Оттавией в неаполитанской траттории. На каждом уровне есть список типичных сбоев.
v1 (`v1/result.md`) выполняет всё, что требует промпт, но в промптах стоят плейсхолдеры `[character block]`, так что вставить их в генератор как есть нельзя. v2 (`v2/result.md` = `result.md`) — самодостаточные промпты, раскадровка по секундам, негативные промпты, таблица нарастания сложности и шкала оценки.
Видео не генерировались: это промпты, их нужно проверять в text-to-video моделях вручную.
