# 16 · Coffee Pirates Canvas
Canvas 2D «видео» на 20 с, которое бесшовно зацикливается: два пиратских корабля кружат и перестреливаются в чашке латте (вид 3/4 сверху). Есть пенка, закрученная curl-noise, волны, вспышки и дым от пушек, молочные брызги с кругами на воде, пар и медленный наезд камеры. Кнопка **Record .webm** через MediaRecorder записывает ровно один цикл и скачивает файл.
Как открыть: `v1/index.html` или `v2/index.html` (без библиотек, можно двойным кликом). v1 работал сразу и без ошибок. В v2 пенка стала глаже и рисуется вдвое быстрее, корабли крупнее, переделаны пар, ручка и блики чашки, вспышка выстрела освещает пену, улучшена вёрстка для телефона.
Что не проверено: сама запись в .webm в headless-браузере не запускалась (MediaRecorder там не тестировался). FPS в песочнице около 25–30, потому что Chromium рисует программно, без видеокарты.
