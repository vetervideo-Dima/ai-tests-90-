Анимированное появление логотипа ORBITA на чистых CSS + SVG (4 с): орбита прорисовывается через stroke-dasharray, планета идёт по offset-path, буквы падают с эластичным easing (`linear()`), по надписи проходит блик, затем включается цикл idle-анимации; есть кнопка Replay.
v1 работает, но белый блик на белых буквах не виден, а буквы стоят с фиксированным шагом (R и B слиплись, вокруг I дыры).
v2: кернинг считается по реальной ширине глифов, у букв градиентная заливка и тени, тёплый цветной блик, ударная волна при замыкании орбиты, хвост кометы и спутник у планеты, свечение без blur-фильтров, подстройка viewBox под портретный экран.
Открыть: `v1/index.html` или `v2/index.html` через локальный сервер или двойным кликом (шрифты подгружаются из Google Fonts, есть fallback).
