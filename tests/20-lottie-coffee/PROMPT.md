# 20 · Lottie Coffee

- **Жанр:** Моушен-дизайн
- **Источник:** по мотивам академических Lottie-бенчмарков. JSON + плеер.
- **Формат выхода:** Lottie JSON + плеер
- **Волна:** 5
- **Корректировка для облачного режима:** JSON + страница-плеер на lottie-web из `vendor/`, проверка валидности JSON.

## Промпт

```
Write a valid Lottie (Bodymovin) JSON animation, 512x512, 60 frames at 30fps, looping: a coffee cup with three steam curves rising and fading, the cup gently squashing (squash & stretch). Shape layers only, no images or expressions. Output only the JSON.
```
