# 20 · Lottie Coffee
Lottie-анимация (Bodymovin JSON 512×512, 60 кадров при 30 fps, в цикле): чашка кофе, три струйки пара и squash & stretch. Только shape-слои, без картинок и выражений. JSON проходит `json.tool`, lottie-web 5.13 рендерит без ошибок.
v1 (`v1/coffee.json`) работает, но у дна чашки кривая форма с «надломом», белый пар почти не виден на кремовом фоне, а поток пара в цикле прерывается. В v2 (`v2/coffee.json`) пар бесшовный (фазы сдвинуты на 0/20/40 кадров) и колышется: трим-пути, морфинг кривой, сужение линии. Добавлены градиенты, блик, тень, которая реагирует на squash, и плеер с паузой и ползунком кадров.
Как открыть: запустите `python3 -m http.server` из корня репозитория и откройте `tests/20-lottie-coffee/v2/index.html` (страница загружает JSON через fetch, из file:// это не работает). `?frame=N` показывает стоп-кадр.
