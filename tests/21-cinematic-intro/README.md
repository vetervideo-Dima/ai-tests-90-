# 21 · Cinematic Intro — «THE LONG QUIET»

12-секундная титровая заставка на three.js (из `vendor/`): дрейф сквозь пылевое облако с DOF-боке, восход звезды над краем планеты с god rays и анаморфным бликом, сборка букв из ~16k частиц с rack focus, хроматическая аберрация, плёночное зерно, леттербокс 2.39:1, финальное удержание титра; Web Audio-дрон (клик для старта) с райзером и ударом на титре.
Открыть `v2/index.html` через локальный сервер из корня репозитория и кликнуть по экрану. v1 — честный one-shot: работал, но из-за переполнения `exp()` в шейдере планеты небо выше горизонта превращалось в NaN (чёрное) с серой «полосой», зерно давало вертикальные полосы, а в SwiftShader он шёл ~1 FPS (стандартный `check.mjs` упал по таймауту скриншота, скрин v1 снят тем же Playwright с увеличенным таймаутом).
v2: фикс NaN, нормальный хеш зерна, god rays с джиттером и затуханием, адаптивное разрешение сцены, меньше/меньшего размера спрайтов, перенос планеты/подзаголовка, подгонка текста под узкий экран. Звук в headless не проверен на слух.
