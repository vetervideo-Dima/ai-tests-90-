# 22 · Pelican Animated

Анимированный SVG (чистый SMIL, без JS): пеликан на велосипеде. Колёса крутятся (2 оборота за цикл, дорога едет со скоростью качения), шатуны вращаются, ноги считаются через обратную кинематику (24 ключевых кадра `d`), шея/голова качаются, три слоя холмов с параллаксом; бесшовный цикл 2 секунды.
Открыть: `v1/pelican.svg` / `v2/pelican.svg` прямо в браузере. v1 работал без ошибок, но на портретном экране обрезался (`slice`), спицы дублировались, деревья висели над холмами, цепь шла назад.
v2: `meet` и сцена, выходящая за viewBox (на мобильном виден весь велосипед), исправлены спицы/деревья/цепь, добавлены лучи солнца, дымка, блики на раме и пеликане, полосы ветра, моргание, перепончатые лапы, «дышащая» тень.
