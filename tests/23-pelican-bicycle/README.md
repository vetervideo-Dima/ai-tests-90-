# 23 · Pelican Bicycle
v1 — статичный SVG 800×600: белый пеликан с огромным оранжевым клювом-мешком на красном велосипеде, крылья на руле, лапы на педалях. Рендерится без ошибок, но жёстко 800×600 (белое поле вокруг), цепь уходит прямо в ось.
v2 — тот же рисунок, но живой: SMIL-анимация вращения колёс и шатунов, лапы крутят педали (кинематика ног просчитана для 24 кадров), покачивание головы, бегущая дорога, трава, холмы и облака (параллакс); градиенты рамы/перьев, свечение солнца, задняя звёздочка и цепь; SVG растягивается на любой экран (фон выходит за viewBox), проверено на мобильном.
Открыть: `v1/pelican.svg` или `v2/pelican.svg` в браузере. Внешних зависимостей нет.
