# 24 · Pelican California — SVG
Калифорнийский бурый пеликан в брачном наряде (жёлтая макушка, каштановая шея с белой полосой, ярко-красное основание мешка, красный крючок клюва, розовое кольцо вокруг глаза) едет на велосипеде с ромбовидной рамой и спицами. Фон — тихоокеанское побережье.
v1 (`v1/pelican.svg`): работает, но поза статичная (крутятся только колёса), мешок закрывает шею, перья нарисованы однообразным узором «кольчуга», SVG фиксированного размера 800×600.
v2 (`v2/pelican.svg`): ноги реально крутят педали (SMIL-кадры с обратной кинематикой: шатуны, звезда, цепь и ступни синхронны), голова покачивается, дорога/облака/блики движутся, перья прорисованы по отдельности, объёмный свет на раме и теле, адаптивный размер и мобильная вёрстка.
Открыть файл .svg прямо в браузере; анимация на чистом SMIL, без JS и библиотек.
