# 26 · Gally Six Scenes
Шесть отдельных SVG 400×400 (ёж с аккордеоном, морская звезда на бульдозере, пингвин с бензопилами, хамелеон у рояля, омар полирует арфу, ленивец в экскаваторе) + HTML-сетка `index.html`, которая их показывает.
v1 работает как есть: все SVG валидны, ошибок в консоли нет; минусы — белые струны арфы почти не видны, «A440» наезжает на крышку рояля, сцены статичные.
v2: CSS-анимация внутри каждого SVG (меха аккордеона, дым и гусеницы, вращение пил, хамелеон меняет цвет, тряпка омара, ковш и «Zzz»), градиенты и тени, цветные струны арфы, сетка адаптирована под мобильные, есть лайтбокс и тёмная тема, учитывается prefers-reduced-motion.
Открыть: `v2/index.html` (или любой .svg напрямую). FPS в песочнице ~14 из-за программного рендеринга.
