# 28 · Isometric Icons
12 изометрических иконок для «домашней студии» (микрофон, камера, софтбокс, ноутбук, наушники, штатив, кружка, растение, микшер, монитор, хлопушка, диск). Их генерирует один JS-движок изометрии: общая сетка 30°, палитра из 9 трёхтоновых рамп, обводка 2px, viewBox 128×128. Страница-сетка позволяет скачать каждую иконку отдельно, весь набор или спрайт.
Открыть: `v2/index.html` (или `v1/index.html`); отдельные файлы лежат в `v2/icons/*.svg`.
В v1 при включении сетки 30° линии выходили за пределы иконок на всю страницу, внизу торчал пустой тост, на мобильном сетка карточек вылезала за экран, а софтбокс, штатив и диск читались плохо. В v2 всё это исправлено, а 12 SVG выгружены отдельными файлами.
