# 29 · Truchet Poster

Генератор печатного A2-постера (420×594 мм, SVG) из многомасштабных плиток Трюше по схеме Карлсона: квадродерево с шумовыми «очагами» дробления, сид, 5 палитр с градиентами в координатах листа, слайдеры размера плитки и плотности, кнопки Regenerate / Download SVG (клавиши R, S, 1–5).
Открыть: `v2/index.html` (параметры сохраняются в `#seed=…&p=…`).
v1 работал без ошибок, но круги-«крылья» и квадраты шли с разной ориентацией в одном path → дыры (светлые пятна), на стыках масштабов — «пакманы», под подписью пустая полоса.
v2: исправлена ориентация, баланс квадродерева 2:1 и принудительная дуга во внешнем углу мелких плиток (стыки бесшовные), волосяная обводка против AA-щелей, сетка заполняет всю рамку, корректная подгонка листа на мобильном.
