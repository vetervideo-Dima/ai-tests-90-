# 30 · Flow Field

Бесконечный генеративный flow field на Canvas 2D: 20 000 частиц по curl-шуму (simplex 3D, поле эволюционирует во времени и дрейфует — не повторяется), аддитивное свечение на тёмном фоне, медленно гаснущие следы, плавная смена палитры каждые 30 с. Клавиши: **S** — сохранить PNG, **Space** — новый seed, **F** — полноэкранный режим (на мобильных — кнопки).
Открыть: `v2/index.html` (итог) или `v1/index.html` (one-shot), без библиотек.
v1 подвисает: штрих 20k отрезков через `Path2D` с `lighter` блокирует главный поток в программном растеризаторе песочницы, скриншот не снимается (на реальном GPU, вероятно, тянет, но проверить не удалось).
v2 рисует в float-буфер с настоящим аддитивным смешиванием, экспоненциальным затуханием (без «грязного» 8-битного остатка) и тонмаппингом. Цвет берётся по направлению потока. Проверено: нет ошибок, Space/S работают, ~18–25 FPS в перегруженной песочнице (на десктопе ~60).
