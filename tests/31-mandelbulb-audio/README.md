# 31 · Mandelbulb Audio

Рэймарчинговый Mandelbulb (GLSL на полноэкранном квадрате, степень анимируется 6→10, переливчатая окраска по orbit trap) + 9000 инстансных аудиореактивных частиц, UnrealBloomPass, медленная орбитальная камера. Звук — сгенерированный Web Audio drone (клик по экрану) или микрофон.
Открыть: `v2/index.html` через локальный сервер из корня репозитория (`python3 -m http.server`), кликнуть для старта звука.
v1 не показывал фрактал: шейдер не компилировался (`projectionMatrix` недоступен во фрагментном шейдере), а камера сидела внутри облака частиц — экран был залит зелёным блумом. В v2 исправлено, добавлены AO, адаптивное разрешение, подгонка камеры под портретный экран.
В песочнице (SwiftShader) компиляция шейдера ~35 с и ~2 FPS — на реальной GPU это не показатель; звук в headless не прослушивался.
