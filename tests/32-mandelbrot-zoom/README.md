# 32 · Mandelbrot Zoom

Бесконечный автозум в Seahorse Valley на WebGL2: f32 на мелких зумах, эмуляция double-float (df64) глубже 1e-6, сглаженная раскраска косинусными палитрами; на h≈2e-11 (зум ~6e10) кроссфейд на новую точку — и так бесконечно.
Открыть `v2/index.html` через локальный сервер или двойным кликом (внешних зависимостей нет). Клик/пробел — следующая цель, H — HUD, `?seek=60` — перемотка в глубину.
v1 работал без ошибок, но CPU-автопилот уже на обзорном зуме уводил камеру из Seahorse Valley; в v2 автопилот включается только в глубине, добавлены DE-подсветка, лог-палитра без шума, проверка периодичности, мобильная вёрстка.
В песочнице (SwiftShader) глубокие кадры рендерятся медленно — динамическое разрешение опускается до 30%; на реальном GPU заметно быстрее, но на слабых видеокартах в глубине картинка будет мягче.
