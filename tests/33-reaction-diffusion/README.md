# 33 · Reaction Diffusion

Модель Грея–Скотта на GPU (WebGL2, ping-pong framebuffers в half-float), всё в одном HTML-файле без библиотек. Есть пресеты coral / mitosis / fingerprints / worms, мышью или пальцем можно рисовать вещество B. Цветовая карта своя для каждого пресета, а «мокрый» блик и френелевское отражение считаются по градиенту концентрации B. Пресеты бесконечно перетекают друг в друга.
Открыть `v2/index.html`. v1 падает на первом кадре и показывает чёрный экран: dt получается отрицательным, и `PRESETS[-1]` оказывается undefined.
В v2 ошибка исправлена. Смена пресета идёт волной от случайной точки, отражение и блик стали студийными (с тенями во впадинах), мазок кисти рисуется непрерывной линией, число шагов симуляции подстраивается под FPS, есть прогрев и мобильная раскладка HUD.
В песочнице (SwiftShader) скорость 2–4 FPS — это программный рендер; на реальном GPU должно быть 60.
