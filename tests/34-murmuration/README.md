# 34 · Murmuration
Стая скворцов на закате (Three.js из `vendor/`): 8 000 боидов (до 12 000) по правилам Рейнольдса с хешированием пространства на CPU, хищный ястреб, крошечные тёмные инстансированные птицы на фоне градиентного неба с облаками, солнцем и силуэтом холмов, медленная кинематографичная камера, слайдеры для правил.
Открыть: `v2/index.html` через локальный сервер из корня репозитория (`python3 -m http.server`), т.к. three грузится по относительному пути `../../../vendor`.
v1 работал сразу без ошибок, но стая выглядела равномерным размытым облаком, солнце не попадало в кадр. В v2: плотная стая с волнами испуга, крен птиц в поворотах, камера смотрит в сторону заката, мобильная раскладка.
Проверено в headless Chromium (SwiftShader): ошибок консоли нет; FPS в песочнице низкий из-за программного рендера, реальную производительность на GPU не замеряли.
