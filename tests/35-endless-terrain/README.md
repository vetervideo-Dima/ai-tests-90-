# 35 · Endless Terrain

Бесконечный пролёт над процедурным ландшафтом на Three.js: чанки 128×128 из фрактального simplex-шума (ridged-горы + domain warp) строятся впереди и переиспользуются из пула позади, биомы по высоте и уклону (песок, трава, скалы, снег), instanced-ели, fresnel-вода, туман, цикл день/ночь за 2 минуты со звёздами и луной; floating origin — может лететь бесконечно.
**v1** — чёрный экран: `THREE.Color` не имеет `addScaledVector`, исключение в каждом кадре до `render()`. **v2** — исправлено + облака в небе (звёзды гаснут за ними), светлее ambient/скалы, лунная ночь, мягче горы, контроль высоты по бокам, бюджет генерации чанков по времени, `?t=сек` для старта с нужного времени суток.
Открыть: `v2/index.html` через локальный сервер из корня репозитория (`python3 -m http.server`). Двойной клик — полноэкранный режим, H — скрыть HUD.
В песочнице (SwiftShader) FPS низкий; на реальном GPU рассчитано на 60 FPS.
