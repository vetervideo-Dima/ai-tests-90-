# 36 · Alpine Shader

- **Жанр:** Бесконечная и генеративная визуализация
- **Источник:** известный промпт (README gokayfem/shader-skills). GLSL + HTML-просмотрщик.
- **Формат выхода:** GLSL + HTML-просмотрщик
- **Волна:** 2
- **Корректировка для облачного режима:** Шейдер обернуть в HTML-просмотрщик (WebGL, uniform iTime/iResolution); исходник mainImage — отдельным файлом.

## Промпт

```
Create a Shadertoy shader (mainImage) of an alpine valley with snow, a winding river and atmospheric depth: raymarched fbm heightfield, soft shadows, aerial perspective, sun glints on the river, slow camera dolly with iTime. Single pass, no textures.
```
