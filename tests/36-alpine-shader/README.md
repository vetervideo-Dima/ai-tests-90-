# 36 · Alpine Shader

Shadertoy-шейдер `mainImage` (`v2/shader.glsl`) альпийской долины: raymarching fbm-рельефа с «эрозией», извилистая река, снег, хвойный лес, мягкие тени, воздушная перспектива, блики солнца на текущей воде, медленный проезд камеры вдоль реки по `iTime`. Один проход, без текстур.
Открыть `v2/index.html` (WebGL2-просмотрщик с uniform `iTime`/`iResolution`/`iMouse`, адаптивное разрешение, перетаскивание — осмотр, пробел — пауза); `shader.glsl` можно вставить в Shadertoy как есть.
v1 работал без ошибок, но был затянут туманом, склоны — гладкие «рампы», и рендер очень тяжёлый. В v2 — шире долина с отдельными пиками и скальными гребнями, лес, LOD октав, облегчённые тени/отражения, портретная камера для мобильных.
В песочнице (SwiftShader) ~3 fps при пониженном разрешении, поэтому скриншоты пикселизированы; на реальной GPU разрешение поднимается автоматически.
