# 37 · Neon Life
Игра «Жизнь» Конвея на чистом WebGL2: тороидальная сетка 1024×1024 считается на GPU (ping-pong текстуры), клетки светятся неоновой палитрой по возрасту, за умершими тянутся затухающие цветные шлейфы, bloom (dual-filter, half-float), ACES-тонмаппинг.
Активность меряется GPU-редукцией + асинхронным readback (PBO+fence); при вымирании, падении активности или «застывании» в осцилляторах автоматически подсеиваются Gosper/Simkin glider gun, пульсары, R-пентамино, acorn, diehard, LWSS и «суп» — работает бесконечно.
Открыть `v2/index.html` (нужен WebGL2). Мышь: рисовать/шифт — стирать, колесо — зум, правая кнопка — панорама; Space/R/C/A/[ ]/0/H. На телефоне: тап/ведение — рисовать, щипок — зум/панорама, кнопки внизу.
v1 работал сразу, но был почти белым (медленное старение) и без мобильного UI; в v2 — неоновая палитра и яркие шлейфы, мобильный HUD с кнопками, перерисовка цвета только при изменениях, убрано PBO-предупреждение Chrome. FPS в песочнице (SwiftShader) низкий — это нормально.
