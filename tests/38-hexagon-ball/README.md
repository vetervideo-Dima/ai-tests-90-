# 38 · Hexagon Ball
v1 — `v1/hexagon_ball.py` (tkinter, только stdlib): мяч с гравитацией, сопротивлением воздуха и трением отскакивает от вращающегося шестиугольника с учётом скорости стенки (ω×r). Запустился под Xvfb без ошибок, за 20 прогонов по 60 с мяч ни разу не вылетел.
v2 — исправленный Python (`v2/hexagon_ball.py`: шаг по реальному времени, вращение мяча от трения, без дребезга в покое, стена рисуется снаружи поверхности коллизии) + веб-порт `v2/index.html` (canvas: неон, искры при ударах, шлейф, панель управления, мобильная вёрстка).
Запуск Python: `python3 v1/hexagon_ball.py` или `python3 v2/hexagon_ball.py` (нужен tkinter); веб — открыть `v2/index.html`. Скриншот окна Python v2 — `v2/screenshot-python.png`.
