# 39 · Heptagon 20 Balls
v1 (`v1/heptagon_balls.py`, tkinter + numpy) запустился с первого раза: 20 мячей падают из центра, отскакивают от вращающихся стен (с учётом скорости стенки и трения → вращение), сталкиваются друг с другом, номера крутятся. Скриншот — через Xvfb.
Проблема v1: шаг симуляции привязан к кадру `after(16)`, а физика на мелких numpy-массивах тратит ~10 мс/кадр — в итоге время идёт на ~62 % от реального, и семиугольник крутится ~360°/8 с вместо 360°/5 с.
v2: `v2/heptagon_balls.py` — фиксированный шаг 480 Гц с аккумулятором по реальным часам (проверено: угол совпадает с ожидаемым), физика на float (в разы быстрее), шейдинг мячей, свечение обода, HUD, пауза/рестарт; `v2/index.html` — веб-порт на canvas с той же физикой, адаптив под мобильные.
Запуск: `python3 v2/heptagon_balls.py` (нужен tkinter и numpy) или открыть `v2/index.html`.
