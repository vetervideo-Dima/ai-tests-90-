# 40 · Nested Hexagons
v1 (`v1/nested_hexagons.py`, tkinter) работает: 5 мячей, 6 вращающихся шестиугольников с одной пропущенной стеной у всех, кроме внешнего; гравитация, трение, спин мячей и передача импульса от вращающихся стен. Скриншот снят через Xvfb. Недостаток: примерно за 40 с все мячи стекают во внешнее кольцо и катаются там.
v2: исправленный Python (`v2/nested_hexagons.py`) с подобранной физикой, чтобы мячи перемешивались по всем кольцам, шагом по реальному времени, переиспользованием объектов canvas, шлейфами и свечением, управлением с клавиатуры и HUD. Плюс веб-порт `v2/index.html` (canvas): ползунки параметров, пинок мячей кликом, неоновый рендер, мобильная раскладка.
Запуск: `python3 v1/nested_hexagons.py` или `python3 v2/nested_hexagons.py` (нужен только tkinter); веб: открыть `v2/index.html`.
