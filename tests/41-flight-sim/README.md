# 41 · Flight Sim — SkyRunner

Лётный симулятор на чистом three.js без ассетов: процедурный бесконечный ландшафт (острова, горы, лес, вода), аэродром с ВПП, самолёт из примитивов с подвижными рулями, физика подъёмной силы/сваливания, HUD (авиагоризонт, курс, скорость), игровая цель — пролёт через кольца, синтезированный звук двигателя.
Открыть: `v2/index.html` через локальный сервер из корня репо (`python3 -m http.server`), клавиши W/S газ, стрелки — тангаж/крен, A/D руль, T — старт в воздухе, X — дым.
v1 работал сразу (без ошибок консоли); мелкий баг — отрицательный dt на первом кадре подбрасывал самолёт на ВПП. v2: LOD-чанки со «юбками» и прогрессивная подгрузка, IBL-освещение от неба, анимированная вода, следы конденсата и дым, тачскрин-управление (стик, газ, кнопки) и компактный HUD для телефона, донастроенная физика (балансировка ~60 м/с, автоудержание крена).
FPS в песочнице (SwiftShader) 5–9 — это программный рендер; полёт проверен ускоренной симуляцией физики (взлёт, вираж, сваливание, посадка).
