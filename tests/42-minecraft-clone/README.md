# 42 · Minecraft Clone — Voxelcraft

Воксельный мир на Three.js (из `vendor/`): чанки 16×16×64 подгружаются вокруг игрока, рельеф из simplex-шума (fbm + горы), процедурные деревья, атлас текстур рисуется на canvas, AO по вершинам, туман. Управление: WASD, мышь (pointer lock), прыжок, полёт (F / двойной Space), гравитация и AABB-коллизии, ломание/установка блоков (ЛКМ/ПКМ/СКМ), хотбар на 9 блоков, дальность прорисовки и «New World» в меню.
v1 работал сразу; в v2 добавлены тач-управление (джойстик, свайп-обзор, кнопки), вода с плаванием и подводным туманом, облака, солнце, покачивание камеры, ускорено меширование (~25 → ~3–5 мс на чанк).
Открыть: `v2/index.html` через локальный сервер из корня репозитория (нужен `../../../vendor`). `?seed=99` — фиксированный мир.
В песочнице (SwiftShader) FPS низкий — это ограничение программного рендера, а не кода.
