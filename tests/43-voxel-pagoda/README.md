# 43 · Voxel Pagoda

Парящий воксельный остров: пятиярусная пагода с бирюзовыми загнутыми крышами и золотым шпилем, вишни (сакура) с опадающими лепестками, глицинии, клёны, сосны, бамбук, клумбы, тории, каменные фонари, пруд с карпами кои и красным мостом. Всё на three.js (из vendor), меш собирается вручную: отсечение скрытых граней и AO по вершинам.
Открыть: `v2/index.html` через локальный сервер из корня репозитория (`python3 -m http.server`). Управление: мышь/тач — вращение и зум, пробел — включить/выключить автоповорот.
v1 рабочий, ошибок в консоли нет. В v2: bloom на фонарях, ручей с водопадом с края острова и брызгами, бабочки, шейдер воды, ускоренный мешинг, мобильная адаптация.
В песочнице FPS около 5 (SwiftShader), загрузка 15–25 с. На реальной GPU должно быть заметно быстрее, но это не проверялось.
