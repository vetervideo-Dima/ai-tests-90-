Неоновая киберпанк-змейка на canvas 2D: шрифты Orbitron + Share Tech Mono (Google Fonts), глитч-заголовок, synthwave-пол, частицы, бонусы, рекорд в localStorage, звуки WebAudio.
Открыть `v2/index.html` (или `v1/index.html`) в браузере; Enter — старт, стрелки/WASD, P — пауза, на телефоне свайпы.
v1 работает без ошибок, но скрытые оверлеи перехватывали клики (клик по центру во время игры перезапускал её), на телефоне поле было мелким, а тело змейки срезало углы при интерполяции.
v2: исправлены клики, вертикальное поле 16×24 для портретных экранов, кнопка паузы и подсказки для тач-устройств, кэш статичного фона, свечение без shadowBlur на сегментах, всплывающие очки, уровни, солнце/звёзды, свет от головы, анимация гибели.
В песочнице (SwiftShader) FPS после нескольких секунд падает до ~7–15 и у v1, и у v2 — это ограничение окружения (простые страницы держат 60), JS тратит ~0.2 мс на кадр.
