# 45 · Solar System
Интерактивная Солнечная система на three.js (vendor): шейдерное Солнце с короной и bloom, 8 планет с процедурными текстурами (canvas-шум), кольца Сатурна с тенью планеты, Луна, кеплеровы орбиты с реальными периодами и положениями на текущую дату, слайдер масштаба времени, плавный переход «Pretty ↔ True scale», перелёт к планете по клику с инфокарточкой.
Открыть: `v2/index.html` через локальный сервер из корня репозитория (`python3 -m http.server`), чтобы подтянулся `../../../vendor/three`.
