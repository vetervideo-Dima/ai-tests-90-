# 46 · Earth Magnetic Field

Three.js-визуализация магнитосферы: процедурная Земля (облака, огни городов, атмосфера), 84 силовые линии, проинтегрированные RK4 из формулы диполя, магнитопауза Шуэ, частицы солнечного ветра, которые обтекают магнитопаузу, захватываются, спирально идут вдоль линий (с магнитным зеркалом) и зажигают авроральные овалы; слайдер ветра, переключатель наклона 11°, панель с 4 абзацами.
Открыть: `v2/index.html` через локальный сервер из корня репозитория (`python3 -m http.server`), three берётся из `vendor/`.
v1 работает без ошибок, но камера смотрит почти навстречу ветру (хаотичные штрихи), Земля мелкая, овалы сияния не видны, ледяные шапки огромные. В v2 это исправлено, плюс поверхность Земли запекается в текстуру, следы частиц не зависят от FPS, есть «тёплый старт», подписи и опциональный звук.
FPS в песочнице (SwiftShader) около 5–8, на реальном GPU должно быть заметно выше; на настоящем GPU не проверялось.
