# 47 · Sorting Sound

8 алгоритмов (bubble, insertion, selection, merge, quick, heap, radix, shell) соревнуются на одном массиве: каждое сравнение звучит тоном Web Audio (пентатоника или непрерывная шкала, панорама по колонкам), счётчики сравнений/обменов, слайдер скорости, панель псевдокода с подсветкой текущей строки и счётчиками попаданий, таблица финиша.
Открыть: `v2/index.html` (кнопка «Start» запускает гонку и звук; Space — пауза, R — новый массив, клик по панели — её псевдокод).
v1 работал сразу без ошибок; в v2 исправлена мобильная вёрстка, шрифты не блокируют страницу, добавлены прогресс «отсортированности», волна финиша без потери цветов, до 3 тонов на кадр.
Звук в headless-проверке не прослушивался — только отсутствие ошибок консоли.
