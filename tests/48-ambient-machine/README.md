# 48 · Ambient Machine

Генеративная эмбиент-машина на чистом Web Audio: бесконечные модальные прогрессии (6 ладов, модуляции, голосоведение), 16-шаговый секвенсор, мутирующий каждые 8 тактов, FM-пэд + Karplus-Strong арпеджио, реверб из сгенерированного шумового импульса, ленточная задержка с wow/flutter; круговой анализатор спектра в цвете текущего аккорда, ручки Mood/Tempo/Volume, большая кнопка Start.
Открыть: `v2/index.html` (нужен клик по Start — браузер требует жест для звука). v1 тоже рабочий.
Проверка: headless Chromium, ошибок консоли нет. Скриншот v1 снят без SwiftShader: с GPU-canvas под SwiftShader `check.mjs` не успевал снять кадр (в v2 это исправлено переключением на CPU-растр при программном GL). Звук на слух в песочнице не проверялся.
