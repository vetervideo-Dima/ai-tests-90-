# 49 · Linux Desktop
Вебовый рабочий стол «Tux Linux» в одном HTML без зависимостей. Окна можно перетаскивать и тянуть за 8 краёв, сворачивать и разворачивать. Есть панель задач с часами и календарём, меню-«пингвин» с поиском. Терминал умеет 50 команд (ls/cd/cat/mkdir/echo, пайпы, `>`/`>>`, `&&`, glob, Tab, история) и работает с файловой системой в памяти. Ещё есть текстовый редактор, файловый менеджер, настройки (обои, светлая/тёмная тема, акцентный цвет) и Paint (кисть, фигуры, заливка, undo). Файлы, настройки, история команд и раскладка окон хранятся в localStorage.
Как открыть: `v1/index.html` или `v2/index.html` двойным кликом или через `python3 -m http.server`.
В v1 два бага: CSS-класс `.sw` совпал у образцов акцентного цвета и у юго-западной ручки ресайза (там видна лишняя окружность, курсор pointer), а Ctrl+S в редакторе сохранял файл дважды. Оба исправлены в v2. Там же добавлены прилипание окон к краям с превью, сворачивание с анимацией в кнопку на панели задач, заставка загрузки, новые обои Peaks и доработки для тач-экранов и мобильных.
