# 50 · ASCII Donut
v1 — `v1/donut.py` (stdlib, 30 FPS): тор с рампой `.,-~:;=!*#$@`, планета на орбите, мерцающие звёзды, ANSI-256 по глубине, z-buffer, SIGWINCH, чистый выход по Ctrl+C. Проверено в pty (120×40, ресайз 90×30→200×60→40×15): стабильно 30 FPS; кадр — `v1/frame.txt`, скриншот — ANSI-кадр, отрисованный в HTML. Минус v1: орбита почти совпадает с тором, планета мелкая и полпериода скрыта, тёмный океан не виден.
v2 — `v2/donut.py` (орбита шире, Blinn-Phong блик, атмосфера/полярные шапки/материки, цветные звёзды с параллаксом, выход по q/Esc) + веб-порт `v2/index.html` (canvas, xterm-256 палитра, 30 FPS, glow, портретная орбита на телефонах, пауза тапом/пробелом).
Запуск: `python3 tests/50-ascii-donut/v2/donut.py` в терминале с 256 цветами; веб — открыть `v2/index.html`.
