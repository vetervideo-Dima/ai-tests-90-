# 71 · Bubbles My Way
Three.js (из `vendor/`): ~1000 мыльных пузырей-импосторов с тонкоплёночной интерференцией, френелем, вобблом и бликами собираются в «MY WAY», держатся, лопаются волной слева направо (кольца + радужные брызги) и разлетаются; бесшовный 12-секундный цикл, мелкая ГРИП через circle-of-confusion в шейдере, клик/пробел — заново.
v1 работает без ошибок, но фон засвечен блумом и огромными боке-шарами, блики пересвечены, мелкие пузыри «зернят» (алиасинг интерференционных полос).
v2: чёрный фон, сочная радужная плёнка с анти-алиасингом, софтбокс-блик, мягкие боке-ореолы, двухстрочная раскладка «MY / WAY» на портретных экранах, масштаб пузырей под размер слова, адаптивный DPR, `?t=8.2` — заморозить момент.
Открыть: `python3 -m http.server` из корня репозитория → `/tests/71-bubbles-my-way/v2/index.html`. FPS в песочнице (SwiftShader) 5–9, реальный GPU должен держать 60.
