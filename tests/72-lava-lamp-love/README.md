# 72 · Lava Lamp Love
Рэймарчинг лава-лампы на чистом WebGL2 (без библиотек): стеклянная колба в тёмной комнате, восковые SDF-метаболы (smooth-min) всплывают/тонут по простой модели плавучести (нагрев у лампочки, остывание наверху), раз в ~28 с сливаются в слово «LOVE», держатся и оплывают обратно; медленная орбита камеры, bloom (bright-pass + размытие), ACES, виньетка, адаптивное разрешение.
Открыть: `v1/index.html` / `v2/index.html` через локальный сервер или двойным кликом (зависимостей нет). В v2 есть `?t=секунды` — сдвиг таймлайна (например `?t=9` — сразу к «LOVE»).
v1 работает, но: огромное серое пятно «окна» на фоне, пересвеченный жёлто-белый воск без глубины, ступенчатые края капель (грубый шаг марша), камера режет основание лампы.
В песочнице (SwiftShader) 3–6 FPS при пониженном разрешении — на реальном GPU ожидается гладко; на мобиле буквы немного пикселизованы из-за адаптивного разрешения.
