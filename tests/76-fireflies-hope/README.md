# 76 · Fireflies Hope

Ночная поляна на three.js: процедурные деревья, луна, слои тумана, ~3600 светлячков на curl-noise, которые слетаются в золотое слово «HOPE», мерцают и разлетаются обратно в лес; медленная панорама камеры, bloom, Web Audio (сверчки + ветер по клику).
v1 работал без ошибок, но слово «HOPE» пересвечивалось в белое пятно, близкие светлячки становились огромными кругами, лес и луна почти не были видны. v2 исправляет это, плюс добавлены градиентное небо с луной в кадре, трава с ветром, свечение тумана от слова, адаптивное разрешение, мобильная раскладка, кнопка mute.
Открыть: `python3 -m http.server` из корня репозитория → `/tests/76-fireflies-hope/v2/index.html` (параметр `?t=15` сразу показывает фазу «HOPE»). FPS в песочнице (SwiftShader) 6–10, на реальном GPU должен быть заметно выше; звук в headless не проверялся на слух.
