# 77 · Powers Of Ten Zoom

Бесконечный зум на чистом WebGL2 (один фрагментный шейдер, без библиотек): Земля → побережье → город с парком → лист → клетки с хлоропластами → молекула хлорофилла → атом Mg → космический фрактал-вихрь → галактика → снова Земля. Каждый уровень приближается в 40 раз, следующий проявляется внутри предыдущего через органическую радиальную маску, стык цикла бесшовный; подпись 10ⁿ m внизу слева.
Открыть: `v2/index.html` (лучше через локальный сервер); пробел/тап — пауза, колесо — скорость, `?s=3.5&pause` — перейти к нужному месту цикла.
v1 рендерит первый кадр, но сразу падает с исключением (отрицательный dt из rAF → индекс уровня −1), анимация стоит. В v2 это исправлено, плюс: заливка парка, сглаживание (LOD) мелких деталей города и звёзд, новый гладкий фрактал вместо зернистого kaliset, более поздняя смена фона, отсечение лишней работы в молекуле.
В песочнице (SwiftShader) шейдер тяжёлый — кадры рендерятся медленно, адаптивное разрешение снижает качество; на реальной GPU ожидается плавно.
