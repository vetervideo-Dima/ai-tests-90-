# 78 · Kaleidoscope Crystal
Бесконечный зум в калейдоскопическую мандалу на чистом WebGL-фрагментном шейдере: 4 слоя log-масштаба с уникальным seed (не повторяется), N-кратная зеркальная симметрия (6–12, клик/тап меняет с плавным кроссфейдом), Voronoi-грани с «преломлением» плазмы, френель/блики, неоновые плазменные потоки по швам, палитра дрейфует пастель↔неон.
v1 работал сразу (без ошибок консоли), но картинка была блёклой/мутной из-за усреднения слоёв. v2: доминирующий слой вместо каши, пропуск невидимых слоёв (быстрее), призматическая дисперсия и ореол на швах, мерцающие блики, ACES-тонмап, дышащий зум, ←/→/пробел и правый клик для обратного шага, мобильный DPR-лимит и safe-area.
Открыть: `v2/index.html` (или `v1/index.html`) через локальный сервер или двойным кликом. FPS в песочнице (SwiftShader) 4–7 — реальный GPU рассчитан на 60 с адаптивным разрешением.
