# 80 · Neon Audio Grid
Аудио-реактивное неоновое шоу на three.js: сгенерированный в Web Audio техно-трек 128 BPM (kick, хэты, клэп, бас, лид с дилеем), бесконечная synthwave-сетка, солнце с полосами, горы, эквалайзер-колонны, арки и wireframe-фигуры под анализатор, bloom, камера «подпрыгивает» на каждый kick.
Открыть: `v2/index.html` через локальный сервер из корня репозитория, кликнуть/тапнуть для старта звука.
v1 не запускается: `SyntaxError: Identifier 'bass' has already been declared` (функция баса и переменная уровня баса с одним именем) — весь модуль падает, виден только экран «click to start».
v2: исправлен конфликт имён, убрана пересветка bloom (картинка была почти белой), затемнён пол/небо, переделано солнце, планировщик аудио на setInterval с ресинхронизацией, Timer вместо устаревшего Clock, широкий FOV в портрете, bloom в половинном разрешении.
