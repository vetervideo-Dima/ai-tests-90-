# 81 · Perfume Shot

Three.js-предметка: тёмный матовый флакон (transmission + clearcoat) с золотой крышкой на чёрном акриловом пьедестале 20×20 см с зеркальным Reflector, ореол-подсветка сзади, узкий боковой свет слева, три бордовых лепестка, поворотный столик, кнопка (только иконка) переключает 5 световых пресетов (также клавиши L/Space).
Открыть: `v2/index.html` через локальный сервер из корня репозитория (`python3 -m http.server`), three берётся из `vendor/`.
v1 работает, но тяжёлый (~1 FPS в SwiftShader, стандартная проверка упала по таймауту скриншота), лепестки выглядели бело-розовыми из-за бликов на скользящих углах, пьедестал обрезан снизу.
v2: своя тёмная «студийная» env-карта из софтбоксов вместо RoomEnvironment, бархатные лепестки, одна карта теней вместо двух, Reflector без MSAA и в 3/4 разрешения, адаптивный DPR, интро-наезд камеры, пылинки в боковом луче, кадрирование под мобильные.
