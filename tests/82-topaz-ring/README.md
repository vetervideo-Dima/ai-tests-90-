# 82 · Topaz Ring
Three.js-предметка: кольцо из 18-каратного золота с овальным голубым топазом 8×6 мм в ореоле из 8 бриллиантов на льне с процедурным плетением (canvas: нити основы и утка, неровности нити, normal map). Камера под 30°, два мягких света под 45°, белый фон, глубина резкости BokehPass, блики-звёздочки, вращение мышью.
Открыть: `v2/index.html` через http-сервер из корня репозитория (three берётся из `vendor/`).
v1 работает без ошибок консоли, но плетение почти не видно, внутренняя сторона шинки и корзинка тёмно-коричневые, бриллианты выглядят бежевыми дисками; в песочнице ~2 FPS, и tools/check.mjs не дождался скриншота (снят отдельным скриптом с большим таймаутом).
v2: светлее окружение и выше контраст золота, белые бриллианты, плетение заметнее, больше бликов, вступительный наезд камеры, автоповорот возобновляется после простоя, адаптивное разрешение (в песочнице оно падает до 0.6, поэтому скриншот пикселизован), вёрстка под мобильные.
